Real estate Data scraping and Predicting-model
Example website: batdongsan (dot) com

First download all the files and then execute as Pipeline showned below:
PipeLine:
1. Running bds_selenium.py to get all the links containing specific pages of each house.
2. Running bds_selenium_multithread.py to collect every housing records.
3. Running bds_cleaning.py to clean the housing data just collected.
4. Running bds_linear_regression.py to predict house price based on Linear Regression Model.
5. Running bds_random_forest.py to predict house price based on Random Forest Model.

You can access the deployed version of this model via the link belowed:
https://house-price-prediction-jk0k.onrender.com/
